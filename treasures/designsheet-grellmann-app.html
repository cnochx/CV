Design Pattern · v2.0 · Refactoring Target · 3D-Transmission Ready

grellmann.app — Warm Glass & Wood

A minimalist, Apple-grade evolution of the existing system: plum-ink glass surfaces, ivory light, two fixed accents, and wood as the grounding material. Every token here is chosen so the site can later be lifted into real 3D without touching content, SEO, or usability.

Supersedes the v1.0 extraction sheet (this file, previous revision). Implementation surface: tailwind.config.js · globalStyles.scss · the 4-value semantic variant enum in SurfaceTokens.tsx · /public/fonts (new). Stack unchanged: Next.js · TypeScript · Tailwind CSS.

1 · Principles

#PrincipleConcrete rule
P1No absolute white or blackLightest value is ivory #f7f4ef / #efe9f2; darkest is ink #16121d. Both carry a hue (warm ivory, plum ink) that ties neutrals to the accents.
P2Two accents, strict rolesFuchsia-400 = identity, rest state, primary action. Cyan-400 = response: active, focus, success, links. They never fight — one surface uses one accent dominantly.
P3Wood is a material, not a colorwood.webp appears as texture behind glass overlays and as a 4px "plinth" bottom edge on cards. Wood tones are never used for text or interactive states.
P4Quiet type, smaller headingsMinor-third scale (×1.2), heading weight 500–600 (never 700), hero caps at ~2.5rem instead of the old 3.75rem. Personality comes from the head family, not from size.
P5Depth is earnedOne shadow pair (--shadow-1/2), translucent glass, and a single aurora hairline gradient. No decorative gradients on fills.
P6Content first, 3D as garnishAll copy is real DOM. Any 3D lives in aria-hidden presentation layers, lazy-loaded, with a 2D fallback identical in content. Zero SEO/GEO cost by construction.
P7Motion glides, never bouncesOne easing (--ease-glide), 180ms color / 320ms movement, hover = −2…3px lift. prefers-reduced-motion flattens everything.
P8No logosNo brand marks anywhere; social links are neutral line icons in circles, identity is set in type only.
P9AA is a token propertyText colors ship pre-paired with their surface (see §2 contrast receipts): ink-400 on ink, ink-500 on ivory, 700/800 accent steps for text on light. Minimum text size 12px (0.75rem) — nothing smaller anywhere, including captions and swatch labels.

2 · Color — the harmonic scheme

Built on the two fixed accents. Fuchsia sits at hue ≈ 292°, cyan at ≈ 187°; the neutral "ink" scale lives between them on the violet axis (≈ 260°) so dark surfaces feel related to both. The light world is warm ivory, which is what makes the wood belong. Contrast rule (WCAG 2 AA, axe-verified): the 400-step accents are text-safe on ink only. On ivory surfaces, text uses the deep steps — primary-700 / accent-800 (≥4.5:1) — and the 600s are demoted to borders, icons and large display type (≥3:1). Muted text is likewise paired to its surface: ink-400 on ink, ink-500 on ivory — never crossed.

3 · Typography

Body: Source Sans 3 (SIL OFL, variable 200–900, self-hosted woff2 ≈ 48 KB) — clear, humanist, Apple-adjacent rendering. Headings: Space Grotesk (SIL OFL, variable 300–700, ≈ 30 KB) — a distinct geometric voice with just enough character for the "solid" brief; used at weight 500–600 with tight −1% tracking. Both live in /public/fonts, loaded with font-display: swap and preloaded — no third-party requests in production. Scale is a minor third (×1.2) from 16px: headings are deliberately smaller than typical; hierarchy comes from family, weight, and space.

5 · Shape, Depth & Z-Space

Depth model with exactly four layers — and, crucially, these are the same layers the 3D transmission will inflate. What is a shadow-and-blur illusion today becomes a real translateZ tomorrow, with no re-design.

LayerToday (2D/2.5D)After 3D transmission
L0 canvasivory-50 / ink-900, wood texture + scrimScene background, static
L1 surfacecards ink-800, glass ink-800/55 + blur, --shadow-1translateZ(var(--z-rest)) plane
L2 raisedhover lift −3px, --shadow-2translateZ(var(--z-raise)) = 24px
L3 floatsticky nav, modal, active card ringtranslateZ(var(--z-float)) = 48px

Shared constants: perspective: 1200px on scene parents · transform-style: preserve-3d on every card wrapper already now · rotation caps ±9° · shadows always from the plum family, never gray. The v1 rim-vignette recipe survives on image cards (it reads as ambient occlusion in 3D).

8 · The 3D Transmission — readiness pattern

Goal: the site can be lifted into an elegant 3D presentation with zero cost on SEO/GEO or usability. The trick is that 3D is never load-bearing: it inflates the §5 layer model that the 2D design already draws with shadow and blur.

Progressive-enhancement ladder

TierWhat shipsWho gets it
T0 · Semantic baseFull HTML content, ivory/ink design, static wood texture. 100% of content lives here.Everyone — crawlers, LLM/geo agents, reader mode, JS-off
T1 · CSS depth ← refactoring targetPerspective parents, preserve-3d wrappers, hover tilts ≤9°, z-token lifts, scroll-driven subtle plane separation (CSS scroll-timeline where supported)Modern browsers, ~0 KB JS cost
T2 · WebGL garnish ← the future transmissionOne lazy React-Three-Fiber scene max per page (e.g. a slowly rotating wooden monolith behind the hero, skill constellation), dynamic(() => …, {ssr:false}), mounted only when its container intersectsDesktop + pointer:fine + hardwareConcurrency ≥ 4 + no reduced-motion + Save-Data off

Hard guarantees (the "no cost" contract)

ConcernRule
SEO / GEO3D canvas is aria-hidden="true", sits in a presentation layer, duplicates zero text. All copy remains SSR'd DOM. Structured data (schema-dts) untouched. No text ever rendered inside canvas.
LCPHero LCP element stays the photo/H1. T2 bundles load after load + intersection; budget ≤ 130 KB gz incl. three.js chunk, else stay at T1.
CLSEvery 3D container has a fixed aspect-ratio box rendered from SSR; canvas fades in over its static poster image (same composition, wood/ink palette).
Input3D layers get pointer-events:none unless the element is genuinely interactive; focus order and anchor navigation identical across tiers.
Motion safetyprefers-reduced-motion collapses T1 to flat and never mounts T2. Scroll-linked rotation capped, no autoplaying camera paths longer than 6s.
Battery / datarequestAnimationFrame paused off-screen (IntersectionObserver), navigator.connection.saveData respected, DPR capped at 1.5.
Materials3D materials sample only §2 tokens: ink glass (transmission + plum tint), oak/walnut PBR from wood.webp, emissive fuchsia/cyan for state — the scene is automatically on-brand.
