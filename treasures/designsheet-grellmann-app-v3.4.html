Designsheet · v3.4 · Refactoring Target · Tier 1–3 Ready

Clean Core.

The Apple-hybrid evolution of grellmann.app: one near-black world, frosted glass as the only surface, light as the material, system type at full scale. HTML-first by construction — 3D is garnish, never content.

Supersedes v2.0 "Warm Glass & Wood" (designsheet-grellmann-app.html): wood, ivory light-world and webfonts are retired; the semantic variant enum, Z-layer model, AA receipts and progressive-enhancement ladder carry over. Implementation surface: tailwind.config.js · SurfaceTokens.tsx · HeaderLayoutSub.tsx · IconButtonLayoutSub.tsx. Stack: Next.js · TS · Tailwind + Framer Motion + Lenis (+ one R3F island).

1 · Principles

#PrincipleConcrete rule
P1One dark worldCanvas is ink-950 #0a0a0c, sections alternate only between ink-950 and ink-900. The ivory light world is retired; "light" exists as text (frost), glass alphas, and glow blobs — never as a background.
P2No pure white or black (kept from v2)Lightest value frost-100 #f5f5f7, darkest ink-950 #0a0a0c. Both carry a whisper of cool hue tying neutrals to the accents.
P3Two accents, strict roles (kept from v1)Fuchsia-400 = identity, rest state, primary action. Cyan-400 = response: active, focus, success, links. One surface uses one accent dominantly.
P4Glass is the surface, light is the materialEvery raised surface is the glass recipe: white-alpha fill + 1px white/10 border + backdrop-blur(20px). Warmth comes from glow blobs behind the glass — this replaces wood entirely.
P5Big type, quiet chromeSystem stack only. Hierarchy from size contrast (hero up to 4.25rem) and weight (700 display / 600 heads / 400 body). Chrome (borders, shadows, icons) stays hairline-quiet so type leads.
P6Accent borders retire to statesv1 painted fuchsia/cyan borders on everything at rest. v3: resting borders are neutral glass; accents appear only as state (active ring + glow), progress, icons, and text highlights. Less color, more meaning.
P7Content first, 3D as garnish (kept)All copy is SSR'd DOM. 3D lives in aria-hidden lazy islands with 2D posters. Text never enters a canvas. Zero SEO/GEO cost by construction.
P8Motion springs, transform-onlyFramer Motion springs (CSS approximation --ease-out), 200ms color / 400ms movement / 700ms reveals. Only transform + opacity ever animate. prefers-reduced-motion flattens everything, kills reactive light and never mounts Tier 2.
P9AA is a token property (kept)Text colors ship pre-paired with their surface (§2 receipts). 0.75rem (12px) is the hard floor for any text.
P10No logos (kept)No brand marks; social links are neutral line icons in glass circles; identity is set in type.

2 · Color — one scale, two accents, glass on top

The three mixed gray families of the live site (gray-800 glass, warm stone-* hovers, neutral-* sections) collapse into one ink scale. Surfaces above the canvas are not colors at all — they are white alphas over blur (the glass ladder), which makes every card automatically harmonize with whatever glow sits behind it. Accents unchanged since v1: fuchsia ≈ 292°, cyan ≈ 187°, ink lives between them at ≈ 250°.

3 · Typography — system stack at full scale

One family: the system stack (system-ui → SF Pro on Apple, Segoe UI on Windows, Ubuntu/Roboto elsewhere). Zero font bytes, native rendering, and the honest way to look "Apple" on Apple hardware. v2's webfont plan is retired. Hierarchy comes from size contrast — the hero returns to v1's boldness and beyond (up to 4.25rem) — and a three-step weight system: 700 display · 600 headings · 400 body. Tracking tightens as size grows (−2% display, −1.5% h2, 0 body).

5 · Depth, Z-Space & Reactive Light

The four-layer model survives from v2 unchanged in structure — only the materials changed. These are the layers Framer Motion parallaxes today and the 3D transmission inflates tomorrow.

Layerv3 material (2D/2.5D)Motion (Tier 1)After 3D transmission

L1 surfaceglass-1 + blur 20 + white/10 border + --shadow-1Scroll-reveal: opacity 0→1, y 24→0, stagger 80mstranslateZ(0) plane
L2 raisedhover: glass-2, lift −3px, --shadow-2, tilt ≤4°, reactive light sheenSpring on hover (stiffness ~300, damping ~24)translateZ(24px)
L3 floatsticky glass nav, active ring + accent glow shadowNav hairline fades in after 24px scrolltranslateZ(48px)

Reactive light (the cursor-following sheen) is a pseudo-element radial gradient at white/9, driven by two CSS custom properties (--mx/--my) from a single delegated pointermove listener — desktop + pointer:fine only, disabled under reduced motion. Tilt caps at ±4° (was ±9° in v2 — Apple restraint). Shared constants: perspective:1200px on scene parents, preserve-3d on card wrappers now, shadows always true black, glows only from accent tokens. Rim vignette stays licensed for image cards only.
